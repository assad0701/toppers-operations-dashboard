# Toppers Operations Dashboard

A responsive operations dashboard built for managing inventory and staff data.

## Live Demo

https://toppers-operations-dashboard.vercel.app

## GitHub Repository

https://github.com/assad0701/toppers-operations-dashboard.git

## Features

- Dashboard overview with inventory metrics
- Inventory CRUD operations
- Staff management CRUD operations
- Low-stock product alerts
- Inventory value calculations
- localStorage data persistence
- Responsive desktop, tablet, and mobile layouts
- Interactive navigation and forms

## Technologies

- React
- JavaScript
- Vite
- CSS
- Recharts
- Browser localStorage
